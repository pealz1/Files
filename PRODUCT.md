# Files Pro

## Register

product

## Users

Windows users who rely on a file manager throughout the day, including power users working across many folders, tabs, archives, projects, cloud locations, and network paths. They need familiar Windows behavior with stronger productivity features and cannot afford UI stalls, runaway background work, or uncertainty around file operations.

## Product Purpose

Files Pro is a daily-driver replacement for Windows File Explorer. It preserves the familiar WinUI and Windows shell model while adding a custom Save dialog, project discovery, indexing, cleanup planning, storage analysis, and other focused power-user tools. Success means navigation and tab interactions respond immediately, large folders remain usable while data loads progressively, long work is cancellable, and file-changing actions stay explicit and recoverable.

## Brand Personality

Fast, familiar, dependable. The interface should feel native to Windows, calm under heavy workloads, and confident without drawing attention away from the user's files.

## Anti-references

Avoid decorative or unfamiliar controls that slow down routine work, blocking loading states, excessive motion, repeated modal interruptions, noisy diagnostics, invisible background scans, and interfaces that become less responsive as tabs or folder size increase.

## Design Principles

1. Acknowledge every interaction immediately, then finish expensive work progressively.
2. Keep background work bounded, cancellable, observable, and owned by the tab or window that started it.
3. Preserve familiar Windows navigation and file-management affordances.
4. Optimize for sustained daily use, not only a fresh launch or an empty folder.
5. Keep destructive file and account actions explicit, reviewable, and recoverable.

## Accessibility & Inclusion

Preserve keyboard navigation, UI Automation semantics, high-contrast resources, system text scaling, and system reduced-motion preferences. Performance work must not remove focus indicators, accessible names, or equivalent non-pointer workflows.
